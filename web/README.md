# git3 marketing site

Next.js landing page for [git3](https://github.com/manasdutta04/git3). Visual language matches [wolverine-scraper](https://github.com/manasdutta04/wolverine-scraper) (brutalist cream / mono / orange).

The **app** is not hosted here — install from npm:

```bash
npx git3 studio
npm install @git3db/db
```

## Develop

```bash
cd web
npm install
npm run dev
```

## Deploy on Vercel

1. Import the `manasdutta04/git3` repo
2. Set **Root Directory** to `web`
3. Framework: Next.js (default)
4. Deploy

Optional project name: `git3` → `https://git3.vercel.app` (or your chosen domain).
